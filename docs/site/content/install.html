安装与升级

Honk 由两个包组成：honk（honk-core 二进制 + 服务脚本 + 默认配置）和 luci-app-honk（LuCI 界面 + 中文翻译 + Doona 资产）。只提供 .apk，不提供 .ipk。

一键安装

以 root 执行。大陆推荐走 jsDelivr 镜像，比各类加速站稳定：

wget -O - https://cdn.jsdelivr.net/gh/kenzok8/openwrt-honk@main/scripts/install.sh | ash

镜像还没同步到最新脚本时，直连 GitHub：

wget -O - https://raw.githubusercontent.com/kenzok8/openwrt-honk/refs/heads/main/scripts/install.sh | ash

脚本会做什么

  • 先查内核版本，低于 6.12 直接退出，不会装一半
  • 从最新 Release 下载两个包并校验，安装包下载默认走 GH_PROXY（https://ghfast.top/），失败回落直连
  • 复用设备已有的 Geo 数据包（v2ray-geoip / v2ray-geosite，与 daede 共用 /usr/share/v2ray）；缺少时从聚合源下载，失败则用设备现有软件源
  • 发现两条默认 BTF 路径都没有时，补装 vmlinux-btf：主次版本一致就装，补丁号不同照装但打警告，跨系列跳过

换加速站：

GH_PROXY=https://你的加速站/ wget -O - https://cdn.jsdelivr.net/gh/kenzok8/openwrt-honk@main/scripts/install.sh | ash

升级

两条路，选一条即可。

① 重跑安装脚本 —— 不用配软件源，最稳，版本一定是最新的 Release。

② 加软件源，之后在「服务 → Honk → 维护 → 软件包更新」里点升级：

wget -qO- https://down.dllkids.xyz/openwrt-feed/openwrt-feed-setup.sh | sh
「软件包更新」卡片只查本机 apk 源，不查 GitHub。用安装脚本装的机器没有把 feed 写进源，卡片会一直显示「已是最新」。想让卡片有用，先跑上面这条软件源脚本（装公钥 + 写源 + 刷索引）。刚发布的版本要等 feed 同步过去才进索引，急着升级就直接重跑安装脚本。

卸载

wget -O - https://cdn.jsdelivr.net/gh/kenzok8/openwrt-honk@main/scripts/uninstall.sh | ash

卸载脚本会停服务、删包。配置留在 /etc/honk/，确认不再使用后手动删除；不清空的话下次重装会直接接上旧配置。
