常见问题

按「现象 → 先查什么」排。改配置前先备份 /etc/honk/（维护页有导出）。

启动失败 / 一直是已停止

  1. uname -r 是否 6.12+
  2. BTF 是否存在：ls -l /sys/kernel/btf/vmlinux /usr/lib/debug/boot/vmlinux
  3. 维护页「系统检查」跑一遍，它会报具体缺哪项
  4. 日志页看最近报错，最多 200 行，凭据已脱敏

更多排查顺序见内核与 BTF。

「打开 Doona」是灰的

Doona 只有在已初始化、正在运行、且 API 就绪时才开放。三个条件任一不满足，按钮就是禁用的。先看概览页的状态卡片，再点启动。

切进来后 DNS 不通

  • 确认监听端口没被别的程序占用：ss -tulnp | grep 9527
  • 确认 LAN 网络选对了（多网段设备容易选成另一个）
  • 看日志里有没有 DNS 上游失败；上游不可达时不会偷偷直连

服务设置是灰的，改不了

config.dae 里自己写了 global / experimental，这些字段就归你的文件管。

  • 保留自己写：设置区继续只读，改配置走「配置」页或手改文件
  • 交给面板：点概览页的「切换为面板管理」，会先备份原文件，再把这两段交给 system.dae

细节见谁在管这份配置。

「软件包更新」一直显示已是最新

这张卡片只查本机 apk 源，不查 GitHub。用安装脚本装的机器没有把 feed 写进源，所以永远显示最新。想让它有用，先跑一次软件源脚本（见升级）。

armv7 能装吗

arm_cortex-a7_neon-vfpv4 和 arm_cortex-a9 有包，但上游只发 x86_64 / aarch64，这两个是源码交叉编译，没有真机验证。跑不通属于正常范围，别拿它当生产环境。

想从零开始

wget -O - https://cdn.jsdelivr.net/gh/kenzok8/openwrt-honk@main/scripts/uninstall.sh | ash
rm -rf /etc/honk /etc/config/honk
# 再跑一次 install.sh
